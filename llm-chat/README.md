# 聊天前端

React 18 + TypeScript + Vite 客服工作台，提供普通模型对话、SSE 流式响应和 RAG 知识库问答。

## 本地运行

在本目录执行：

```powershell
npm ci
npm run dev
```

默认端口 `3098`。本目录的 `npm run dev` 只启动前端；整组服务从项目根目录运行 `npm run dev`（前端 + RAG）或 `npm run dev:all`（前端 + 两个后端）。打开 [客服工作台](http://127.0.0.1:3098) 后先进入右上角「设置」，选择模式并测试连接，再打开右下角客服窗口。

首次使用默认选择「直连 API」。启动 RAG 服务后，需要手动改为「实训四 RAG」；已有设置会从浏览器恢复。

| 模式 | 地址与配置 | 依赖 |
| --- | --- | --- |
| 直连 API | `/tokenhub/v1`、API Key、模型 `hy3` | Vite 开发代理，转发到 TokenHub 国内站 |
| 实训二代理 | `http://127.0.0.1:11434`，选择已配置模型 | `api-proxy` |
| 实训四 RAG | `http://127.0.0.1:14052` | `llmchat_Rag` |

设置与聊天记录使用浏览器本地存储。RAG 的 `session_id` 随会话传给后端，回复支持展开引用来源和执行步骤。RAG 返回完整答案，不使用普通聊天的流式响应开关；模型和密钥由 RAG 后端配置。

重新生成只替换最后一轮回答，保留此前上下文。后端重启后，浏览器中的旧消息仍会显示，但服务端上下文已清空，需要新建对话。RAG 请求失败时，聊天气泡会显示 HTTP 状态及后端提供的错误说明，具体含义见 [项目常见问题](../README.md#常见问题)。

## 验证与构建

```powershell
npm run lint
npm run build
npm run preview -- --host 127.0.0.1 --port 3099 --strictPort
```

`lint` 检查代码规范，`build` 先进行 TypeScript 检查，再将静态资源生成到 `dist/`，`preview` 用于本地预览构建结果。当前保留这些命令，已清理使用完毕的测试代码与工具。

静态资源使用模块导入，生产构建会生成可用资源地址。模型输出的原始 HTML 按文本显示，Markdown 与代码高亮仍可使用。设置面板会忽略过期的模型列表请求，避免切换模式后被旧请求覆盖。

生产静态部署需为 `/tokenhub` 配置反向代理，或改用可访问的代理/RAG 服务。附件仅本地预览，转人工为演示回复。更多配置和功能边界见 [项目 README](../README.md)。
